# Grahana Checking — UI Refresh

Revisi visual frontend berdasarkan project asli yang dikirim.

## Perubahan
- Navigasi publik: Beranda, Jelajahi Bali, Layanan, Alur, About, dan Akses Pemerintahan.
- Direktori tetap mendukung kategori Accommodation, Restaurant, dan Mall, pencarian, pengurutan, serta detail usaha.
- Kartu direktori memakai visual berbeda berdasarkan kategori.
- Bagian Layanan memisahkan kebutuhan wisatawan dan ruang pemeriksaan pemerintahan.
- Bagian Alur menjelaskan langkah penggunaan.
- About diperluas dengan penjelasan platform.
- Dashboard, CRUD, riwayat, laporan, import/export, validasi, dan penyimpanan lokal tetap dipertahankan.
- Navigasi dan layout responsif untuk desktop dan perangkat mobile.

## Menjalankan
```bash
npm install
npm run dev
```

## Catatan operasional
Ruang pemeriksaan dalam frontend ini mengelola data pada perangkat/browser. Verifikasi legalitas resmi tetap harus dilakukan melalui instansi berwenang. Jangan masukkan dokumen rahasia atau data pribadi sensitif.
