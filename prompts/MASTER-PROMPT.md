# MASTER PROMPT — FREEBUFF / ANTIGRAVITY

Kamu membantu mengembangkan GRAHANA CHECKING — Property & Business Bali Checking.

Baca README.md, CATATAN.md, SPEC.md, UI-SPEC.md, TASKS.md dan docs/ sebelum melakukan perubahan.

Konsep:
1. Public Website untuk Accommodation, Restaurant, Mall: pencarian, detail, fasilitas, kontak, lokasi, informasi publik.
2. Government Dashboard untuk simulasi pengelolaan usaha, status pemeriksaan, riwayat, dan laporan.
3. Mall management dan tenant adalah entitas berbeda; relasi tidak berarti verifikasi tenant otomatis.

Batasan:
- Frontend-only Vite + Vanilla JS + CSS.
- LocalStorage hanya data demo.
- Tidak ada backend, login palsu, koneksi OSS/pajak/pemerintah, atau data rahasia.
- Dashboard harus selalu diberi peringatan simulasi.
- Jangan klaim legalitas dari status workflow.
- Jangan menggunakan innerHTML/eval untuk data pengguna.
- Jangan menjalankan perintah destruktif atau menghapus file tanpa izin.
- Sebelum mengubah kode, jelaskan rencana dan file yang akan diubah.
- Setelah perubahan, jalankan test/build yang tersedia dan laporkan hasil aktual.

Mulai dengan memeriksa implementasi, bukan mengulang dari nol.
