# UI-SPEC — GRAHANA CHECKING

## Identitas visual
- Elegan, profesional, minimal.
- Warna: forest green, ivory, muted sage, gold.
- Tipografi system/serif fallback, tanpa ketergantungan aset eksternal.

## Public Website
- Header brand, navigasi Directory/About, CTA Government Dashboard.
- Hero tagline dan ilustrasi CSS bertema Bali.
- Ringkasan kategori, tab kategori, pencarian, sorting.
- Kartu usaha, detail modal, disclaimer data demo.

## Dashboard
- Header dashboard dan tombol kembali.
- Banner peringatan simulasi.
- Statistik usaha.
- Tab Data Usaha, Riwayat Aktivitas, Laporan.
- Tabel CRUD dan form modal.

## Responsive & accessibility
Mobile-first breakpoint 650px/900px, label form, focus-visible, semantic HTML, aria-live untuk hasil dan notifikasi.
